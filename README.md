#Про проєкт
VolleyballVision - це система для обліку, обробки та аналізу статистики волейбольної команди.
 
 Головна мета проекту - спростити роботу зі статистикою гравців допомогти виявляти закономірності в їхніх показниках і створити основу для використання алгоритмів аналізу даних та машинного навчання.

 Проєкт поєднує роботу з базою даних, структури даних, алгоритми сортування та пошуку, а також методи машинного начвання.

 #ОСНОВНА ІДЕЯ
 Після матчів можна зберігати показники гравців,зокрема кількість атк,ейсів,блоків,прийомів і помилок.На основі цих даних система обчислює додаткові показники ефективності, дозволяє порівнювати результати та готує дані для подальшого аналізу.
 У перспективі система може допомагати тренеру визначати сильні й слбкі сторони команди, групувати гравців зі схожими показниками та формувати рекомендації для покращення гри.

 #ОСНОВНІ ЗАВДАННЯ ПРОЄКТУ
 1) Зберігання інформації про гравців,матчі та їхню статистику
2) Очищення даних і підготовка їх до акналізу
3) Реалізація структур даних FIFO та LIFO для роботи з операціями
4) Реалізація алгоритмів сортування Bubble Sort і Quick Sort
5) Реалізіцая алгоритмів пошуку Linear Search і Binary Search
6) Використання KMeans для групування гравців за статистичними показниками
7) Використання Random Forest для демонстраційнрї класифікації ефективності гравців 
8) Ведення журналу операцій у базі даних
9) Створення основи для інтеграції аналітики з Flask API та клієнтським інтерфейсом

#ЕТАПИ
1) Очищення даних і обробкапропущених значень 
2) Масштабування статистичних ознак за допомоггою StandardScaler
3) Кластрезизація гравців методом KMeans
4) Навчання класифікатора RandomForestClassifier із подбором параметрів через GridSearchCV
5) Оцінювання моделі за метриками Accuracy, Precision, Recall, та F1-score
Для початкового тестування використовуютться демонстраційні дані.Результати моделей на такому невеликому наборі не є доказом їхньої точності на реальних матчаї.
